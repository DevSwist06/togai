# Contributor instructions

Read `rules/README.md` and `rules/definition-of-done.md` before changing this project. Follow the architecture, testing, and security rules linked there. Every addition requires appropriate regression coverage, documentation updates, and a successful `npm run verify` with zero warnings/errors and all tests passing. Never bypass the pre-commit gate, weaken checks to obtain a pass, stage unrelated changes, or claim checks ran when they did not.
